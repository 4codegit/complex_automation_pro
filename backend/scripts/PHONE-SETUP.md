# Телефон = датчики + пульт (Modbus TCP) — настройка за 5 минут

Используется приложение **Modbus Slave Simulator** с нашей доработкой:
кнопка **РАНДОМ-РАН / СТОП**. Работает в двух режимах:

- **РАНДОМ-РАН** — все 28 сенсоров «дышат» (блуждание ±13%, тик 0.7 с),
  графики трендов на мониторинге живые, как на настоящем заводе;
- **СТОП** — значения замораживаются; двойной клик по сенсору задаёт точное
  число, которое видно в мониторинге как есть (статический «реальный» замер).

APK (сборка 8, с кнопкой и «Пультом»): `~/android-build/dist/Modbus_Slave_Simulator.apk`
(появится после сборки; без доработки — [релиз v1.0.0](https://github.com/4codegit/modbus-slave-simulator/releases/tag/v1.0.0)).

## Подключение: USB-кабель (рекомендуется) или Wi-Fi

**USB (надёжнее для защиты, телефон заряжается):**
1. Соедините телефон и ноутбук кабелем.
2. На телефоне: «Настройки → Точка доступа → USB-модем» (USB tethering).
3. Приложение слушает `0.0.0.0` — кабель работает так же, как Wi-Fi.

**Wi-Fi:** телефон раздаёт точку доступа, ноутбук подключается к ней.

## На телефоне (2 минуты)

1. Установите APK (разрешите установку из неизвестных источников).
2. Приложение открывается на вкладке **«Пульт»** — минимальный экран, три кнопки:
   - **«♒ Пресет 'Флотация' (28 датчиков)»** — заполнит все 28 сенсоров
     и 9 актуаторов (точная копия регистров проекта);
   - **РАНДОМ-РАН** — включить «дыхание» сенсоров;
   - **СТАРТ СЕРВЕРА** — поднять Modbus-сервер (индикатор зелёный, под ним адрес).
   Сетевые настройки (IP/порт/Unit ID: `0.0.0.0`, `5020`, `1` — по умолчанию,
   не менять) и точные значения — на остальных вкладках.
   Настройки по умолчанию менять не нужно.

## На ноутбуке (1 команда)

```bash
backend/scripts/phone-modbus.sh        # сам найдёт телефон (USB или Wi-Fi)
```

Скрипт проверяет шлюзы всех маршрутов (включая USB-модем 192.168.42.129),
затем сканирует подсети. Поднимает capd (:8000) и edge (опрос 1 раз/с +
обратная запись команд в регистры телефона). Мнемосхема: http://127.0.0.1:8000
(operator/operator).

## Сценарий демонстрации

1. **Живой график:** РАНДОМ-РАН на телефоне → вкладка «Тренды» на панели
   показывает «дыхание» датчиков.
2. **Точный замер:** СТОП → двойной клик по `AI301` → ввести `950` (=9.50 pH)
   → мониторинг показывает ровно это число.
3. **Двустороннее управление:** контур LIC301 в АВТО на мнемосхеме → платформа
   пишет выход в HR 4 телефона → во вкладке Holding приложения значение
   меняется само.

## Проверка связи

```bash
cd backend && go run ./cmd/mbprobe <ip-телефона>   # прочитает IR0..27 и HR0..6
```

Если скрипт не нашёл телефон: `backend/scripts/phone-modbus.sh <ip-телефона>`.
Порт < 1024 на Android требует root — оставьте 5020.
