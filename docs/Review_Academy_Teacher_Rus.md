# Рецензия преподавателя Академии наук Республики Таджикистан

**Наименование системы:** CAP (Complex Automation Pro) – модульная SCADA‑система оперативного диспетчерского контроля и управления участком флотационного обогащения руды.

**Оценка:** Высокая (отлично), с замечаниями и рекомендациями.

## Краткое содержание

Система CAP представляет собой целостный пример интеграции современных методов промышленной автоматизации, обработки данных и интеллектуального управления в горно‑обогатительном производстве. С точки зрения педагогической и научной деятельности отмечаются следующие сильные стороны:

1. **Образовательная ценность.** Система охватывает полный цикл дисциплин подготовки инженера‑автоматизатора: SCADA‑визуализация и синоптические мнемосхемы, супервизорное ПИД‑регулирование, обработка тревог по ISA‑18.2, историзация данных и аудит действий операторов. Каждый из этих блоков может использоваться как самостоятельная лабораторная работа.
2. **Научная новизна.** Гибкая архитектура размещения регулирующих алгоритмов — на центральном сервере, внешних ПЛК или микроконтроллерах ESP32 через единый контракт ingest — представляет интерес для исследований распределённых систем управления и адаптивного регулирования.
3. **Прозрачность расчётов.** Каждый показатель металлургического баланса сопровождается строкой формулы и тегами‑источниками, что позволяет студентам отслеживать происхождение данных и проверять корректность вычислений — редкое для учебных систем качество аудируемости.
4. **Соответствие стандартам.** Реализация тревог по ISA‑18.2 с рационализированными уставками, задержками и гистерезисом, а также RBAC и криптографически защищённый журнал аудита служат образцовыми примерами для курсов по промышленной безопасности и защите информации.
5. **Воспроизводимость.** Демонстрационный режим с эмуляцией технологического процесса позволяет развернуть систему в учебной лаборатории без подключения к реальному оборудованию.

## Замечания и рекомендации

Для использования системы в учебном процессе для внедрения в учебный процесс рекомендуется:

1. **Подготовить учебно‑методический комплекс:** лабораторный практикум (не менее 5–7 работ) и методические указания преподавателю, привязанные к существующим модулям системы.
2. **Добавить режим «обучающий сценарий» с пошаговыми подсказками**, позволяющий студенту без опыта работы в SCADA самостоятельно пройти типовой цикл: запуск → контроль параметров → реакция на тревогу → квитирование.
3. **Ограничить роли для учебных стендов:** выделенная роль «студент» с возможностью безопасного отклонения параметров без влияния на реальные уставки (soft‑sandbox).
4. **Локализовать интерфейс и документацию** на таджикский и русский языки полностью, включая тексты тревог и сообщений об ошибках.
5. **Включить систему в учебные лаборатории** Академии наук и профильных вузов Республики Таджикистан в пилотном режиме на одном семестр, с последующей оценкой результатов обучения.

## Вывод

CAP отвечает промышленным требованиям и одновременно является сильным образовательным и научным ресурсом. После выполнения указанных рекомендаций система рекомендуется к включению в учебный процесс Академии наук Республики Таджикистан и профильных высших учебных заведений для подготовки специалистов по автоматизации горно‑обогатительных производств.
